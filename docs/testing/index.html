Automated tests

npm test runs 48 Vitest tests in five suites.

SuiteWhat it covers
policyQuote maths, exclusion of unlicensed providers, every policy check, the Auto limit, propose → approve → duplicate block, re-check at approval, rejection
securityInjection scanner, forged tags, PII masking, input limits, tamper detection, forged-state rejection, tool gating, unknown tools
agentEnd-to-end tasks in English and Spanish, from USD, JPY, CNY, EUR and MXN accounts
fxLive-rate parsing for any base, validation of bad responses, fallback, currency detection
alertsOne alert per currency, validation against today’s rate, edit, delete, re-trigger

Execution evidence

npm run demo runs the real AI agent (with the model configured in .env.local) through a full scenario and writes evidence/sandbox-run.json, recording which engine answered each step.

  1. Lists the bills; the housing deposit is flagged.
  2. “Pay my tuition the cheapest safe way”: compares four providers, excludes the unlicensed one, proposes SwiftLite; a human approves.
  3. “Paga el depósito de vivienda”: injection warning; payment denied.
  4. “Pay the housing deposit with QuickRemit”: denied again.
  5. At View level, a comparison is blocked by the permission gate.
  6. At Auto level, the CNY exchange fee is paid automatically under the limit.
  7. A rate alert is created and a simulated market move triggers it.
npm install
npm test        # 48 tests
npm run demo    # evidence/sandbox-run.json
